Design System

One language for every workplace.

Tokens, type, components and motion rules extracted from the People Prime logo — steel-blue for trust, amber for human warmth. Every value on the website is read from tokens.css; nothing is hard-coded.

01 · Principles

Trust first

Blue carries structure and credibility. Large calm surfaces, generous space.

Warmth as accent

Amber is reserved for the single most important action or a human highlight per view.

Cinematic, not noisy

Motion reveals hierarchy; it never competes with content. Respect reduced-motion.

Accessible by default

AA contrast minimum, visible focus rings, semantic HTML, 44px touch targets.

08 · Motion
--ease-outcubic-bezier(.2,.8,.2,1) — all UI & reveals
--ease-cinemacubic-bezier(.77,0,.18,1) — letterbox / hero intro
--dur-fast180ms · colour, links
--dur-base350ms · hover, buttons
--dur-cinema1200ms · scroll reveals
  • Reveal: translateY 40px + blur 8px → rest, stagger 80–150ms.
  • Headlines unmask line by line.
  • 3D scene colours are read from tokens — blue nodes, amber "leaders".
  • Camera moves only on scroll; ambient motion stays under 0.3 rad/s.
  • prefers-reduced-motion disables grain, float and reveals.
09 · Developer conventions

File structure

assets/
 ├ css/tokens.css      ← source of truth
 ├ css/components.css  ← .btn .card .badge …
 ├ js/tailwind.config.js ← maps tokens
 ├ js/icons.js  ui.js  scene.js
 └ logo-mark.svg

Rules

  • No raw hex or px magic numbers — use tokens (bg-brand-600, var(--space-6)).
  • Repeated pattern ⇒ component class; one-off layout ⇒ Tailwind utility.
  • Tailwind for layout (grid/flex/gap), components for look & feel.
  • Change a colour once in tokens.css; UI and WebGL update together.
  • Semantic HTML, aria-label on icon-only controls.
